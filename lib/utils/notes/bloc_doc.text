### BLoC Pattern: How It Works

#### Diagram:

```
      +----------------+                     +-------------------+
      |                |                     |                   |
      |  User Input    |    SignUpSubmitted   |   SignUp Event    |
      |  (Button Click)| ------------------->|                   |
      |                |                     +-------------------+
      +----------------+                                |
                                                        |
                                                        v
      +----------------+                     +-------------------+
      |                |                     |                   |
      |     SignUp     |      mapEventToState|   SignUp Bloc     |
      |    Loading      | <------------------|                   |
      |                |                     +-------------------+
      +----------------+                                |
                                                        |
                                                        v
      +----------------+                     +-------------------+
      |                |                     |                   |
      |    SignUp      |   SignUp Success   |   SignUp State    |
      |    Success      | <------------------|                   |
      |                |                     +-------------------+
      +----------------+                                |
                                                        |
                                                        v
      +----------------+                     +-------------------+
      |                |                     |                   |
      |     UI         |                     |    Display        |
      |    Update       |                     |   Success/Error   |
      |                | <-------------------|                   |
      +----------------+                     +-------------------+
```

### Step-by-Step Process:

1. **User Input**:
   - The user fills in their name, email, and password in a form and clicks the "Sign Up" button.

2. **Event Generation**:
   - When the user clicks the button, a `SignUpSubmitted` event is generated.
   - This event notifies the BLoC that the user is attempting to sign up.

3. **Entering the BLoC**:
   - The event goes into the `SignUpBloc`, which handles the sign-up logic.
   - The `mapEventToState` function is called.

4. **State Change**:
   - The BLoC first changes to the `SignUpLoading` state to indicate that the process is ongoing.

5. **API Call**:
   - The BLoC creates a sign-up model and makes an API call to register the user.

6. **Success or Failure**:
   - If the sign-up is successful, the BLoC changes to the `SignUpSuccess` state.
   - If the sign-up fails, the BLoC changes to the `SignUpFailure` state and provides an error message.

7. **UI Update**:
   - The UI responds based on the state changes.
   - If successful, the UI shows a success message. If it fails, the UI displays an error message.

### Benefits of the BLoC Pattern:

- **Clear Logic**: The BLoC pattern keeps the logic clean, making it easier to understand and manage the code.
- **Reactive UI**: The UI reacts automatically to state changes in the BLoC.
- **Reusability**: The BLoC can be reused across different UIs.
